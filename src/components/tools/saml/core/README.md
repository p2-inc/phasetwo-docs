# SAML decoder core

Framework-free TypeScript behind the [SAML Decoder](https://phasetwo.io/tools/saml-decoder). No React, no Docusaurus, no DOM, no dependencies, and no network access. It relies only on `crypto.subtle` (WebCrypto), `DecompressionStream`, `TextEncoder`/`TextDecoder`, and `atob`/`btoa`, so it runs unchanged in browsers, extension pages and service workers, and Node 22+.

Files import each other with explicit `.ts` extensions so Node can run them directly with type stripping. Copy the directory as a whole.

## Quick start

```ts
import {
  analyzeSaml,
  parseTrustInput,
  verifyXmlSignatures,
  verifyRedirectSignature,
} from "./core/index.ts";

const a = await analyzeSaml(pasted, { now: Date.now() });
if (a.error) console.warn(a.error);
a.decoded.detected; // "HTTP-Redirect URL with SAMLRequest (base64 + DEFLATE), signed in the query string"
a.summary; // structured fields: messageType, issuer, destination, assertions[], status, …
a.times; // validity-window checks with relative times and clock-skew notes
a.hints; // troubleshooting + Keycloak-aware hints
a.pretty; // pretty-printed XML as highlightable tokens

const { keys, errors } = await parseTrustInput(certPemOrMetadataXml);
const xmlSigs = await verifyXmlSignatures(a.document!, keys);
const querySig = a.decoded.signature
  ? await verifyRedirectSignature(a.decoded, keys)
  : undefined;

// Cross-check a request with the response it produced (either order).
const x = await analyzeExchange(requestInput, responseInput, {
  now: Date.now(),
  clockSkewSeconds: 30,
});
x.checks; // [{ id: "in-response-to", status: "match" | "mismatch" | …, expected, actual, detail }, …]
```

## API

| Module        | Exports                                                                                                                                                                                               | Purpose                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `index.ts`    | everything below                                                                                                                                                                                      | Barrel re-export of the modules in this directory.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `analyze.ts`  | `analyzeSaml(input, { now?, clockSkewSeconds? })` → `SamlAnalysis`                                                                                                                                    | One call: decode, parse, summarize, time-check, hint, pretty-print. Never throws; problems land in `error`.                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `compare.ts`  | `compareRequestResponse(request, response, { responseBinding? })` → `ComparisonCheck[]`; `analyzeExchange(requestInput, responseInput, opts)` → `ExchangeAnalysis`; `isRequestType`, `isResponseType` | Cross-checks an AuthnRequest with its Response (or LogoutRequest with its LogoutResponse): message types, InResponseTo vs. ID (message and SubjectConfirmationData), IssueInstant order, ACS URL vs. Destination and Recipient, request Issuer vs. Audience, NameIDPolicy vs. NameID format, RequestedAuthnContext (honoring `Comparison`) vs. AuthnContextClassRef, and ProtocolBinding vs. the binding the response arrived over. Each check is `match`, `mismatch`, `warning`, `info`, or `skipped`. `analyzeExchange` swaps inputs pasted in reverse order. |
| `decode.ts`   | `decodeSamlInput(input)` → `DecodedInput`; `base64ToBytes`, `bytesToBase64`, `inflate`                                                                                                                | Detects raw XML, base64, base64+DEFLATE, URL-encoded values, query strings / form bodies, and full URLs. Records `steps`, `binding`, `relayState`, `sigAlg`, `signature`, and the exact `signedQuery` octets for redirect signatures. Inflation is capped at 5 MB.                                                                                                                                                                                                                                                                                              |
| `xml.ts`      | `parseXml(xml)` → `XmlDocument`; `XmlParseError`; `childElements`, `firstChild`, `descendants`, `attr`, `textContent`, `lookupNamespace`, `inScopeNamespaces`                                         | Small namespace-aware parser. Rejects DOCTYPE (no entity expansion). Applies XML end-of-line and attribute-value normalization so canonicalization is exact.                                                                                                                                                                                                                                                                                                                                                                                                    |
| `saml.ts`     | `summarizeSaml(doc)` → `SamlSummary`                                                                                                                                                                  | AuthnRequest, Response, LogoutRequest/Response, bare Assertion, and metadata fields; per-assertion subject, confirmations, conditions, audiences, AuthnStatements, attributes; encrypted-assertion count; which elements are signed; structural warnings (duplicate IDs, nested assertions).                                                                                                                                                                                                                                                                    |
| `times.ts`    | `checkTimes(summary, { now, clockSkewSeconds?, nearSeconds? })` → `TimeCheck[]`; `hasClockSkewSymptom`, `relativeTime`, `parseSamlInstant`                                                            | Validity-window evaluation with plain-English notes.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `hints.ts`    | `samlHints(summary, { decoded?, times?, now? })` → `Hint[]`; `parseKeycloakUrl(url)`; `LINKS`; `DOCS_ORIGIN`                                                                                          | Status-code explanations, Destination/Recipient mismatches, unsigned messages, clock skew, and Keycloak-specific advice keyed off `/realms/{realm}/protocol/saml` and `/realms/{realm}/broker/{alias}/endpoint`. Link `href`s starting with `/` are phasetwo.io paths — prefix them with `DOCS_ORIGIN` outside the site.                                                                                                                                                                                                                                        |
| `explain.ts`  | `NS`, `STATUS_CODES`, `explainStatusCode`, `NAMEID_FORMATS`, `BINDINGS`, `AUTHN_CONTEXT_CLASSES`, `SUBJECT_CONFIRMATION_METHODS`, `ATTRIBUTE_NAME_FORMATS`, `WELL_KNOWN_ATTRIBUTES`, `lookup`         | Plain-English dictionaries.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `x509.ts`     | `parseTrustInput(text)` → `{ keys, errors, source }`; `parseCertificate(der)`                                                                                                                         | Loads trusted keys from PEM certificates / public keys, a bare base64 certificate, or metadata XML (signing `KeyDescriptor`s). Reports subject, issuer, validity, and SHA-256/SHA-1 fingerprints. Ignores private-key blocks.                                                                                                                                                                                                                                                                                                                                   |
| `dsig.ts`     | `listSignatures(doc)`, `verifySignature(doc, info, keys)`, `verifyXmlSignatures(doc, keys)` → `SignatureCheck[]`; `verifyRedirectSignature(decoded, keys)`; `algorithmName`                           | XML-DSig verification for the SAML profile: enveloped signatures, same-document references, enveloped-signature + (exclusive) C14N transforms, RSA-SHA1/256/384/512 and ECDSA-SHA1/256/384/512. Enforces that a signature signs its parent element and that the referenced ID is unique. Unsupported algorithms or shapes return `status: "error"`, never a false "valid". Certificates embedded in `KeyInfo` are reported but never trusted.                                                                                                                   |
| `c14n.ts`     | `canonicalize(element, { exclusive, withComments?, inclusivePrefixes?, exclude? })`; `c14nOptionsFor(uri)`; `C14N_ALGORITHMS`                                                                         | Canonical XML 1.0 and Exclusive XML Canonicalization 1.0 (with `InclusiveNamespaces PrefixList`).                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `pretty.ts`   | `prettyPrintTokens(doc)` → `XmlToken[]`; `prettyPrintXml(doc)`                                                                                                                                        | Display-only formatting; token kinds are `punct`, `tag`, `attr`, `ns`, `value`, `text`, `comment`, `pi`, `space`.                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `examples.ts` | `EXAMPLES`, `EXAMPLE_EXCHANGE`, `EXAMPLE_IDP_CERTIFICATE`, `EXAMPLE_SP_CERTIFICATE`                                                                                                                   | Fully synthetic signed examples, the certificates that verify them, and the matching request/response pair.                                                                                                                                                                                                                                                                                                                                                                                                                                                     |

## Not supported (by design)

- Decrypting `EncryptedAssertion` / `EncryptedID` / `EncryptedAttribute` — that needs the SP's private key.
- XPath / XSLT / base64 transforms, detached or enveloping signatures, DSA and RSA-PSS signature methods, and certificate-chain or revocation checking. These return an error result instead of a verdict.
