# Phase Two: September 2026

Keycloak shipped two patch releases in September and closed twenty-six CVEs between them.
Read **26.7.4** first: upgrade this week if your login or SAML endpoints face the internet.

## Official Keycloak

- **🔐 Keycloak 26.7.4**: six CVEs, five rated high — upgrade this week if your login or
  SAML endpoints face the internet, because two are unauthenticated DoS.
  ([our write-up](/blog/keycloak-2674-released/))
- **🔐 Keycloak 26.7.3**: twenty CVEs. Not an emergency, but upgrade this week if you use
  external token exchange or fine-grained admin permissions v2 — and 26.4–26.6 have no
  patch yet. ([our write-up](/blog/keycloak-2673-released/))

## Open source releases

- **🏛️ Organizations v0.182**: closes an information leak about existing users, and stops
  the membership paths loading the full member collection on large populations. ([docs](/extensions/organizations/))
- **🔗 Magic links v0.85**: new account-activation and activation-or-reset email
  authenticators, failed email OTP attempts now count towards brute force protection, and
  passkeys work alongside Cloudflare Turnstile. ([docs](/extensions/magic-link/))
- **🧙 IdP wizard v0.56**: a rebuilt wizard v2 with new SAML, OIDC and OAuth wizards, Okta and
  Entra ID SCIM wizards, selected per realm at runtime and still defaulting to v1 during the
  staged rollout. ([docs](/extensions/idp-wizard/))
- **🎨 Themes v0.80**: email template overrides now work inside the theme's branded shell,
  and the OrgMember route no longer requires the `view-clients` role.
  ([docs](/extensions/themes/))
- **🔑 KMS key provider v0.1**: first release — realm signing keys are wrapped by a cloud
  KMS, so the database holds ciphertext instead of a PEM private key. ([docs](/docs/security/))
- **⚛️ Atomic auth flows v0.2**: first tagged release of the extension built with Gusto — it
  imports flows, configs and bindings in one transaction and rejects an identical re-import
  rather than duplicating it. ([read more](/blog/keycloak-atomic-auth-flows/))

## Phase Two hosting

- **🖥️ Custom domains now serve app association files**: upload
  `apple-app-site-association` and `assetlinks.json` from the dashboard, and mobile apps can
  autofill saved passwords — and share passkeys — with your Keycloak login page.
  ([read more](/blog/app-association-custom-domains/))
- **🔎 Telemetry Export ships logs and events to your own OTLP endpoint**: point an
  Enterprise cluster at your collector and its logs and authentication events arrive in
  whatever you already run. Experimental, on request.
  ([read more](/blog/telemetry-export-experimental/))
- **🖥️ Every console action is now an API call**: the Management API, an API credential you
  mint yourself, and a generated Terraform provider — all three experimental, so point them
  at test environments while the surface settles.
  ([read more](/blog/phasetwo-management-api/))
