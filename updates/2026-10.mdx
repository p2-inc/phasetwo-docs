# Phase Two: October 2026

Phase Two shipped thirty-eight extension releases this month across seven repositories,
with Organizations, magic links, themes, events and webhooks and atomic auth flows all
rebuilt on Keycloak 26.8.0. The notable fixes: an account enumeration hole in magic links,
and N+1 queries gone from organization listings.

Upstream closed forty CVEs across **26.7.5**, **26.8.0** and **26.8.1**. Read 26.8.1 first
and upgrade this week if you broker SAML or use mTLS. On 26.6 or 26.4, read 26.7.5 too: it
fixes a critical CVE in a bundled library, and neither branch has a patched tag yet.

## Official Keycloak

- **🔐 Keycloak 26.8.1**: 19 CVEs, none above medium in Keycloak itself, plus an unrated
  SAML broker bypass — upgrade this week if you broker SAML or use mTLS.
  ([our write-up](/blog/keycloak-2681-released/))
- **🔐 Keycloak 26.8.0**: SCIM, multi-cluster v2 and client secret rotation promoted to
  supported, token exchange delegation added, seven CVEs fixed.
  ([our write-up](/blog/keycloak-2680-released/))
- **🔐 Keycloak 26.7.5**: 14 CVEs, one critical in a bundled library — upgrade this week on
  26.7, and note that 26.6 and 26.4 have no patched tag yet.
  ([our write-up](/blog/keycloak-2675-released/))

## Phase Two open source releases

- **🏛️ Organizations v0.192**: on 26.8.0, with the N+1 queries gone from organization
  listing and membership lookups, and an index on `ORGANIZATION_DOMAIN`.
  ([docs](/extensions/organizations/))
- **🔗 Magic links v0.94**: closes an account enumeration hole in the continuation flow,
  stops invalid email input creating a user, and fixes the Turnstile config check.
  ([docs](/extensions/magic-link/))
- **🎨 Themes v0.89**: the email preview renders the realm's own brand tokens, so what you
  see is what sends, plus a neutral `phasetwo-ui` welcome theme.
  ([docs](/extensions/themes/))
- **🪝 Events and webhooks v0.66**: the `ext-event-email` listener is registered properly,
  and `includedEvents` parsing no longer falls over on unexpected input.
  ([docs](/extensions/events/))
- **🧩 Admin portal v0.63**: the sign-in profile handles passwordless WebAuthn credentials
  correctly, and shows the password row when the user has one.
  ([docs](/extensions/admin-portal/))
- **⚛️ Atomic auth flows v0.4**: rebuilt on 26.8.0, no functional change since v0.2.
  ([read more](/blog/keycloak-atomic-auth-flows/))
- **🧙 IdP wizard v0.57**: a build pipeline sync, no functional change.
  ([docs](/extensions/idp-wizard/))
